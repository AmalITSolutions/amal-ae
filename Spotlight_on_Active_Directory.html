Active Directory real-time diagnostic tool instantly identifies and resolves problems

Get the information you need to resolve issues before they impact users, with Spotlight™ on Active Directory Pack. This troubleshooting and diagnostics tool monitors Microsoft Active Directory performance and can help you improve user productivity. With quick and easy deployment, you can obtain next-step suggestions and invaluable diagnostic data just minutes after installation. Even if you’re a beginner, there’s no learning curve, so you can use Spotlight immediately after deployment to help identify the root cause of MS Active Directory problems.


Features


  • Expedites resolution with intelligent interpretation and easy-to-understand troubleshooting tips
  • Alleviates time-consuming manual troubleshooting and improves administrator productivity
  • Pinpoints and diagnoses directory problems using in-depth troubleshooting diagnostics
  • Delivers early warning of directory problems for fast, efficient prevention and resolution
  • Provides error resolution with context-sensitive knowledgebase that provides practical advice
  • Integrates with System Center Operations Manager (SCOM) 2007 R2 and 2012 64 bit only
  • Improves system uptime through real-time visual indication of resource bottlenecks on domain controllers and drill-down resolution capability
  • Allows administrators to make critical AD decisions by trending analysis data and providing a graphical summary of the most essential parts of AD
  • Enables real-time diagnostic analysis of remote DCs
  • Offers more than 100 customizable tests and automated repairs
  • Diagnoses and alerts on critical Active Directory conditions—including replication, Operations Masters, active directory DNS functions, domain controllers, Global catalogs and application partitions — in real-time
  • Provides an exchange view that highlights how active directory impacts exchange environments
  • Flexible Topology View allows you to filter Active Directory view to focus diagnostic efforts
