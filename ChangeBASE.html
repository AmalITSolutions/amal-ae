Simplify the process of ensuring application readiness

Accelerate application delivery and cut your migration time and cost in half with ChangeBASE. Reduce risk by automating application testing, OS patch impact testing, remediation, packaging and virtualization.

ChangeBASE also retains your post-migration optimizations and eliminates tedious, repetitive and manual tasks. Easily find and fix application compatibility issues, detect application dependencies and conflicts, and assess browser compatibility for better ongoing maintenance. And ChangeBASE helps speed application delivery, so you’ll get back the time you need while seeing big savings in your application management system.


Features

Application discovery and rationalization

Quickly identify your software assets and get a complete application inventory.

Windows OS patch impact and dependencies assessment

Run complete patch impact assessments to help speed deployments and reduce security risks to keep up with Microsoft security updates.

Application compatibility testing and remediation

Reduce the risk of post-deployment failures by identifying, testing and automatically remediating compatibility issues before deploying applications to the target environment.

Automated application virtualization and packaging conversion

Automate conversion of packages to App-V, ThinApp, XenApp, SWV and MSI formats.

Complete MSI packaging tool

Use MSI Studio for full Windows Installer editing and repackaging capability — eliminate the need for expensive third-party solutions.

Microsoft Office dependency testing

Identify applications with Microsoft Office dependencies to enable faster migration testing.

Browser compatibility

Automatically detect compatibility issues with web applications running on Edge, Internet Explorer, Chrome and Firefox browsers.

Application readiness dashboards

Gain insight into platform compatibility and quickly identify potential migration issues across your entire application estate at a glance.

Intuitive and comprehensive reporting

View the results of compatibility assessments, patch impact, dependency analysis and much more through the rich reporting capabilities — including SQL Server Reporting Services (SSRS) integration.

Automated bulk importing

Import applications directly from a shared network path or Microsoft System Center Configuration Manager.

Bulk auto-fix compatibility issues

Automate remediation for many OS and virtual compatibility issues detected.

Customized packaging checks

Ensure compliance with in-house and MSI packaging standards by creating custom compatibility checks and fixes that can be cloned and shared.
